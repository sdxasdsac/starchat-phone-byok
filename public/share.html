先在线体验（不用部署）→

如果上面的 Deploy 按钮打不开、或出现 403 Forbidden：这是 Vercel 对部分网络的拦截， 不是项目问题。开启代理/VPN 后刷新即可部署；只想先看看效果的话，直接点上面这个绿色按钮。

只有三步

  1. 点上面的 Deploy to Vercel，用 GitHub 授权登录。
  2. 什么都不用填，点 Deploy。一两分钟后拿到你自己的 https://xxx.vercel.app。
  3. 打开网址 → 桌面「设置」→ 填 Base URL / API Key / 模型名（DeepSeek、OpenAI 都行）→ 开始聊天。

装到手机，像 App 一样用

AndroidChrome/Edge 打开网址 → 菜单 → 安装应用 / 添加到主屏幕。
iPhoneSafari 打开 → 分享 → 添加到主屏幕。

装好后全屏运行、无地址栏；长按图标还有「聊天 / 微信 / 素材仓库」快捷方式。
