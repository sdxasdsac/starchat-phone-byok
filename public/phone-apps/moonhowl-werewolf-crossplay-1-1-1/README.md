# 月夜狼杀 🌖🐺

沉浸式深色文游风格的**可联机狼人杀**自定义 APP。

**豪华版**:全套新艺术金线版画风美术(6 张角色牌 + 卡背 + 10 位人偶画像 + 4 款旅人头像 + 昼/夜/黄昏场景 + 首页主视觉),内嵌思源宋体子集,月相转场、出局盖印动效,设备端合成的氛围音效(可在「语音与开麦」里关闭)。想替换美术:用同名文件覆盖 `assets/*.webp` 重新打包导入即可。

## 安装

1. 打开小手机 → 应用广场 / 自定义 APP → **本地导入**
2. 选择 `moonhowl-werewolf.zip`,确认权限即可

## 玩法

### 单机开局
- 首页 → **单机开局**,选板子(六人~十二人或自拟)
- 可勾选**多位自己的角色**一同上桌,余位由 10 位内置人偶自动补齐
- 人偶按真实开黑局来写:打字慢的大叔、术语一串的老手、上班摸鱼的、只会跟票的新人、爱抬杠的、记票型……说现代口语,不是话本人物。配置了 AI 会真的推理发言;没配置 AI 也有兜底台词,随时可玩

### 联机开房
- **创建房间**生成 4 位邀请码,念给朋友,对方在「加入房间」输入即可
- 每位玩家 = 本人 + 可携**一位**自己的角色上桌(角色由主人设备驱动、消耗主人 token,人设不出门)
- 人数不足时开局自动以人偶补位;全员**备战**后房主点「天黑请闭眼」开局
- 房主逻辑权威:发牌、夜晚结算、计票均在房主端运行并广播

### 游戏流程(常规规则)
分牌 → 夜晚(守卫→狼人→预言家→女巫)→ 天亮报死讯(首夜死者有遗言)→ 依次发言 → 投票放逐(平票 PK 加投)→ 循环至一方胜出。
- 守卫不可连守同一人;同守同救视为无效(奶穿)
- 女巫解药毒药各一瓶,同夜不可并用;解药仅首夜可自救,第二夜起被刀不能自救
- 猎人被刀/被票可开枪,中毒枪哑;支持连环枪(夜里被刀也先开枪再判胜负)
- 屠边规则可开关(默认开)

### 开麦(语音)
- 首页 → **语音与开麦**:打开「为角色开麦」后,你带上桌的角色发言时会用 TA 的声线实时朗读(内置人偶不出声)
- 「为角色开麦」与「旁白播报」**默认都是关闭**,想听声音先在这里打开
- 角色若在小手机里绑过专属声线,自动用 TA 自己的声音;旁白使用你选定的声线
- 发言输入框旁的 🎤 支持语音转文字(浏览器 STT)
- **切人等念完**:角色发言若要朗读,播放端会先告诉引擎「等我念完」,音频真正播完再切下一位(而不是按字数估时长)。三道保险:60 秒封顶防卡死、队列溢出补回执、关麦打断也补回执
- 角色发言优先于旁白:积压的旁白会被丢掉(文字早已上屏),否则开局第一句能被旁白堵三十秒
- **联机语音互通**(设置里默认关闭):打开后
  - 你的角色发言时,**合成好的音频直接广播给同桌** —— 全场听同一份声音,TTS 只在你这边花一次钱,不是每人各合成一遍
  - 你按麦克风说话时,**原声也播给别人**;同时语音识别照常出文字,AI 和角色靠文字读懂你说了什么
  - 只有打开的人才听得见别人的语音
  - 实现:音频按 12000 字符切片经 `room.send` 广播(上限 16000 字符/条、25 条/秒),错开 70ms 发送给游戏消息留配额;单条音频超过约 650KB 就不广播
  - 真人原声依赖宿主的 `voice.record`(沙盒 iframe 拿不到麦克风,录音必须由宿主页代劳)
- **音量可调**:牌局顶栏有音量按钮(🎙 图标),进行中随时能调,不用退出;首页「语音与开麦」里也有同样的「语音音量」「音效音量」两条滑杆(宿主 `voice.play` 支持 `volume`)。人声正在响时音效自动压到两成半——宿主的 `ambience` 与 `voice` 是两个独立 `<audio>`,会同时出声,钟声压在人声上就会发闷
- 界面音效(钟声、翻牌、盖印)在设备端合成成 WAV 后**交给小手机代播**(`voice.play` 的 `ambience` 声道),和角色语音走同一套播放器。沙盒 iframe 里的 Web Audio 在 iOS 上会被静音拨键掐掉输出,所以不能直接播;预览模式(不在小手机里)才回落到 Web Audio

### 狼人夜晚
- **先商议再落刀**:AI 狼的密谈发言走 LLM(读白天发言、前情、同伴已说的话),不是模板套目标
- **真轮流,不是齐声喊**:第 N 头狼要等前面 N 位同伴实际开过口才发起调用(只按时间错开没用——LLM 要跑几秒,后一个发起时前一个还没广播,两边看到的记录都是空的,就会说出雷同的话)。后开口的会被明确要求「别重复同伴的提议,要么表态跟刀,要么换人并说理由」
- 商议窗口结束后才各自落刀,落刀时读得到**完整密谈记录,包括你打的字**;提示里要求优先跟上同伴商定的人选,所以你说「刀6号」队友是真会跟
- 桌上有真人狼时商议窗口 24 秒,纯 AI 局 11 秒;夜晚时限 95 秒
- 代码硬校验:绝不会刀到自己队友。刀口标记每头狼提交后即广播给全狼队

### 投票
- **全场发言结束后**才进入投票,每个 AI 席各跑一次 LLM,读完当天完整讨论再决定投谁(不是随机、也不是拍脑袋的公式)
- 狼人不会投自己的队友(提示词要求 + 代码硬校验双保险);预言家优先投出手上的查杀
- LLM 超时或抽风时回落到「当天被点名热度」,仍然跟着讨论走
- 投票时限 75 秒(要留给 AI 真思考);票型全量入档,后续所有发言与决策都能看到「谁投了谁」

### 人偶的记性
- **座位名单**:每次发言/决策都带上全场名单(几号叫什么、谁已出局)。以前完全不给,AI 只能从别人发言里反推有谁,第一个开口的等于闭眼说话
  - 不标「真人/人偶/角色」——那是元信息,写进 prompt 很出戏,对推理也没帮助
  - 你那一席叫什么,取决于谁在看:**人偶**和**别人带的角色**看到你的狼人杀昵称;**你自己带的角色**看到「昵称(该角色绑定的人设名)」两个都给(`user.getProfile({characterId})`)。小手机允许每个角色绑不同人设,所以同一个你在 A 角色眼里和 B 角色眼里可以是两个名字。人设名与昵称相同则不重复写;你出局后合并成一组括号,如 `1号月下独酌(阿昭,已出局)`
  - 「昵称(人设名)」只出现在喂给你自己角色的 prompt 里,牌桌界面和广播给别人的一律只用昵称
  - 联机时昵称会经 `setName` 报给房主(房间玩家列表给的是小手机账号名,不是本 APP 昵称);在房里改昵称会补报一次
- **身份类**永久记得:自己的牌、狼队友、预言家的全部查验、女巫药况
- **战况**跨天累积(谁夜里没了、逐票票型、放逐结果),不占发言窗口——第 5 天也记得第 1 天谁投了谁
- **发言**窗口按板子大小走(座位数 ×4,夹在 40~72 之间),带座位号署名与「遗言/PK台」标记;主持词不占坑

### 界面
- 顶部相位标签 + 计时条,当前发言者座位高亮 + 声波动效
- 右上 📜 随时翻看**全场发言记录**(可筛选发言/局面/狼人密谈)
- 夜晚狼人可开**狼人密谈**面板文字商议、查看队友刀口标记

## 权限说明
| 权限 | 用途 |
| --- | --- |
| online.play | 联机房间 |
| ai.generate / ai.chat | 角色与人偶的发言生成 |
| characters.read | 选择带上桌的角色 |
| user.profile.read | 读你的用户人设名,让角色按它认识的称呼叫你 |
| voice.tts / voice.stt / voice.readProfiles | 开麦朗读、语音输入;联机原声广播的录音沿用 `voice.stt` 权限 |
| app.data.read / write | 记住你的偏好设置 |
| ui.toast | 操作提示 |

## 已知边界
- `room.send` 为房间内广播,身份等私密信息靠各端按 `to` 约定过滤——足够朋友局使用,但打开开发者工具的作弊者理论上可窥屏,请勿用于赌上尊严的比赛 :)
- 游戏进行中无法中途加入;玩家掉线由人偶自动接管其座位(真人席与其带的角色席都会转成人偶,底牌/狼队友/预言家查验会由引擎补发给接手的房主)
- 房主为逻辑权威,因此房主设备上握有全部人偶席的底牌与狼队密谈(要驱动它们)。界面不显示,但开发者工具下理论可见——朋友局够用,别拿它打正式赛
