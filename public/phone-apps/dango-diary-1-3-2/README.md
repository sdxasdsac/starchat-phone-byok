# 团子共养日记 1.3.2

**Codex × Fish 联合创作**

给每一个角色，一只不一样的小可爱。一起照顾、聊天、写日记，收藏那些只属于你们的温柔。

## 1.3.2 动物线条修正

整套界面改为封面小兔对应的淡粉平面手绘风：

- 奶白纸张底纹、轻柔的粉色铅笔边框和细线导航。
- 手绘窗帘、草莓花瓶、格纹地毯组成的小窝背景。
- 聊天使用便签式气泡，日记采用信纸、回形针与秘密信封样式。
- 删除动物身上的重复铅笔描边和抖动滤镜，恢复干净柔和的插画轮廓。
- 每种动物使用符合物种的默认色：狐狸暖橘、熊猫黑白、青蛙苔绿、小鲸雨蓝等。
- 每只动物另有 3 款适合它的自然毛色可选，不再给全部动物统一套香草黄。
- 六套主题保留，配合统一的纸张、边框和房间配色。
- 小兔子封面保留原画风。图片与样式已内置，没有新增权限或外部资源请求。

原有互动功能和存档结构沿用。美化素材经过渲染检查，19 组模拟功能检查通过；尚未完成真实小手机中的浏览器视觉验收。

## 老用户：保留存档更新

1. 退出已经打开的团子应用。
2. 小手机 → **应用市场 → 创作 → 本地测试**。
3. 找到「团子共养日记」，点击 **换包**。
4. 选择 `团子共养日记-v1.3.2.zip`，完成更新后重新打开。

不用卸载。新版沿用原应用的数据集合，打开时会补齐新字段；原来的名字、成长记录和角色陪玩内容保留。旧团子的形态保留为「糯米团」，可以到装扮页主动换成新动物。首次保存后使用新版存档格式，后续请继续使用新版本。

## 新用户：安装

**应用市场 → 创作 → 导入整包 → 选择 ZIP → 本机测试**，不用解压。

打开后选一位角色，确认小动物种类，取个名字，点「欢迎回家」。也可以从角色聊天室「＋」中的「团子小窝」进入，自动定位对应角色。每个角色各有独立的小窝、外形、配色、聊天和日记。

## 这次有什么

### 24 位小伙伴

糯米团、小猫、小狗、垂耳兔、小狐狸、小熊、熊猫团、仓鼠、松鼠、刺猬、小鹿、小绵羊、小啾、小鸭、企鹅、猫头鹰、海豹、水獭、小鲸、小龟、小青蛙、水豚、六角龙、小龙。

都是内置的可缩放原创 SVG 图形，不依赖外部图片，不需要生图就能完整玩。每种动物有 **3 款物种专属自然毛色**，另有 6 种头饰、6 种窗边摆件。

### 每个角色，不同的小宠物

- **首次领养**：根据角色可读取的设定关键词做本地匹配，没有明显关键词时给出一个稳定的初始选择。无需 API；这只是趣味推荐，不是心理分析。
- **装扮 → 按设定匹配**：重新查看本地推荐方案。
- **装扮 → 请 AI 设计**：使用宿主角色生成接口，结合完整角色上下文，在内置动物中设计种类、配色、头饰、宠物性格和画像提示。
- AI 方案只先预览，点击「用这个设计」才保存；保留宠物原名和成长进度。
- 也可以直接在动物图鉴里选自己喜欢的形象。

### 六套小清新主题

**草莓奶昔（默认粉色）、薄荷花园、晴空苏打、香芋云朵、蜜桃乌龙、香草奶油**。

在装扮页切换，小窝、按钮、日记和聊天配色一起改变；每位角色的小窝分别保存主题。图标使用用户提供的小兔子形象重新设计：奶白长耳、粉色蝴蝶结、耳朵上的爱心与浅粉背景。

### 小动物会和你说话

去 **说说话** 页，输入一句话，点击「说给它听」。小动物使用自己的名字、种类、性格、小窝记录和最近对话回应你。

这是 **文字互动**，不包含语音朗读。宠物对话使用小手机的通用文本模型接口，与扮演照顾者的角色生成链路分开。保留最近 15 轮对话，不会冒充已经调用过 AI；本地试玩会明确提示需要导入宿主。

### 两种新日记

- **爪爪日记**：在日记页点击「让宠物写小日记」，让小动物从自己的视角写下被照顾的感受。依据已有小窝记录，不要求每天打卡。
- **秘密信箱**：点击「写一页悄悄话」，生成角色对宠物说的一段小秘密。点击信封里的「拆开」阅读，也可以合上。

悄悄话是依据角色设定 **即时生成的小剧场**，不是读取真实隐藏聊天。这些内容不会自动发给角色，也不会加入宠物聊天的上下文；秘密条目没有分享按钮。这里的「秘密」是玩法名称，不是加密存储。

所有日记合计保留最近 **120 条**。普通成长日记和爪爪日记可以通过按钮分享回当前角色的聊天，分享后不会自动触发另一轮模型回复。

### 可选：AI 专属画像

去 **装扮 → 画一只专属小动物**，可输入额外外观要求，再点击「生成专属画像」。

- 使用小手机里已启用的 **生图 API**。未配置时会提示，内置动物仍可正常玩。
- 每次点击生成一张，可能消耗你配置的服务用量。不会自动生图、后台补图，也不会要求输入 API Key。
- 根据宠物种类、性格、配色和外观要求绘图；不使用角色的参考人像。
- 接受 PNG、JPEG 或 WebP 图片。通过宿主媒体库保存，数据库只存引用，避免把大图塞进每条存档。
- 每位角色收藏最新一张画像。切换到内置外形后，可用「使用已收藏画像」恢复。
- 修改内置动物、颜色或头饰，不会修改已经生成的图片；想要新画面，需要再次点击生图。

## 日常互动

喂幻想点心、摸摸、盖被被；睡着时先叫醒再喂食或摸摸。喂食和摸摸有 4 秒间隔。点「请 TA 来陪玩」会调用角色模型，角色根据自身设定与你和宠物一起互动。

这些是幻想养成玩法，不是真实动物的喂养建议。小动物不会因离线而生病或离开，没有付费道具和打卡惩罚。

## API 与保存说明

- 宠物聊天/爪爪日记：`ai.chat`，使用小手机的可用通用 API 配置。
- 角色陪玩/性格设计/悄悄话：`ai.generate`，使用宿主的角色上下文和对应场景预设。
- 专属画像：`ai.generateImage`，使用已配置的生图服务。
- 所有 AI 调用由按钮触发，不设后台定时生成。模型可能产生服务用量，输出风格也受所配置模型影响。
- 生成成功但保存失败时，会出现「只重存，不重新生成」。内容留在当前页面，重存不再调用模型；请保存成功再退出。媒体已经保存时，重试也不会重复存入新副本。
- 未能读取存档时暂停操作，避免把旧记录覆盖成空白。
- 应用包不包含用户角色资料、API Key 或私人存档。卸载且选择删除数据时，宿主会清理应用数据和媒体。
