theqoo · Float 资源集市独立版 v1.1.2 使用教程

一、安装

把本 ZIP 作为「应用」资源上传到 Float 资源集市。其他用户在资源详情页点击导入后，会直接安装到自己的小手机，并在桌面出现 theqoo 图标。

二、第一次打开

1. 顶栏右侧语言按钮只切换 App 界面语言，不等于帖子翻译模式。
2. 设置 → 世界书：只勾选希望 theqoo 读取的世界书。未勾选的世界书不会主动进入论坛生成上下文。
3. 设置 → 内容关联：可以选择是否参考手机日历。关闭时完全不读取日历；开启后也只允许明显属于公开活动的日程偶尔成为讨论素材，私人安排不会被当成公开爆料。

三、首页刷新与搜索

顶栏「↻」是论坛刷新键：
- 随机生成最多 10 篇新帖子，其中至少 2 篇是独立 HOT；
- 同时处理此前仍处于待回复状态的用户评论。

搜索栏则必须输入关键词后才能搜索。搜索只负责围绕关键词生成最多 10 篇帖子，其中至少 2 篇是独立 HOT，不顺便处理待回复评论。全部页同一话题只显示一次，HOT 不会同时挂到普通板块；新生成的帖子会尽量避开已有话题。

四、帖子与评论

AI 刷新的帖子每篇会带 10 条匿名评论。滚到评论底部点击「查看更多评论」，每次继续生成 10 条；有待回复的用户评论时，先完成下一次首页刷新再使用此按钮。

用户自己发布的新帖子默认 0 条评论，不会自动出现网友回复。

用户在帖子下发表评论后，评论先进入待回复状态。论坛不是即时聊天，所以 AI 不会马上围着用户回复。等下一次点击首页刷新键时，如果这条评论仍然存在，系统才会把它连同帖子上下文一起交给 AI，本轮为该帖子新增 5~8 条评论。

因此，如果发完评论后反悔，可以在刷新前直接删除。已经删除的评论不会参加下一轮生成。

五、楼主标识

用户自己发布的帖子中，用户自己的评论会显示「楼主 / 글쓴이」。

AI 生成的普通帖子中，也可能出现原帖楼主匿名回来补充或回复，同样显示这个标识。

例外：新闻、资讯分类不会生成 AI 楼主回复。

六、论坛评论生态

新闻和资讯的“正经”只限制标题和正文：
- 新闻正文偏报道、转述；
- 资讯正文偏整理、说明、实用信息。

评论区仍然是匿名论坛，可以自然出现嘲笑、吐槽、风凉话、反驳、争论、阴阳怪气、小规模吵架，也可以有人认真补充。

其他分类同样允许意见冲突；具体人物、关系、圈内梗、事件背景仍以安装者自己勾选的世界书为准。

七、翻译设置

设置 → 翻译设置里有一个总开关。

关闭翻译模式：
- 新生成的标题、正文、评论全部只生成中文；
- 不额外生成韩语版本；
- 不调用翻译 API；
- 中文仍保持韩网内容翻成中文后的语感、句法和网络表达。

开启翻译模式后，可以选择：
- 全是韩文：只展示韩文原文；
- 折叠翻译：韩文原文 + 可展开中文；
- 搬运风翻译：韩文原文 + 中文搬运式翻译。

八、翻译 API

翻译 API 只用于「用户本人输入」：
- 用户发帖；
- 用户评论。

AI 自动生成的帖子与评论不会再拿翻译 API 二次翻译，而是在内容生成时直接按当前翻译模式要求输出。

可以开启独立翻译 API，并填写 Base URL / API Key / Model。若不启用独立翻译 API，则自动使用当前 Float Chat API 完成用户输入的中韩翻译。

九、图片与文字图

所有图片相关文字统一使用中文：
- 用户添加的文字图直接按中文保存；
- AI 自动生成的文字图只生成中文；
- 文字图不调用翻译 API；
- AI 生图描述请用中文填写；
- 生图提示会明确要求画面中出现的可见文字只能是简体中文，禁止出现韩文/韩语文字。

十、分享到 Chat

帖子可以分享给安装者自己 Float 中的角色。角色列表读取安装者当前的小手机，不写死 ii-phone 的角色。

关闭翻译模式时，分享卡片使用中文帖子内容；开启翻译模式时，会把中韩双语帖子快照一起放入分享上下文。

十一、资源版与 ii 内置版的区别

资源集市版只保留「手机日历」内容关联，不依赖 WVS。

ii-phone 内置版则可以同时选择：
- 参考手机日历；
- 参考 WVS 公开日程。

刷新和搜索时可返回桌面继续生成；此功能要求宿主支持自定义 App 后台保活。旧版 Float 未提供该能力，退出会中断。关闭网页也会中断。
